# Interactive Calculator & Unit Converter

A beginner-friendly Python CLI program that performs basic arithmetic,
unit conversions, and currency conversion.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero validation
- Kilometers to Miles conversion
- Celsius to Fahrenheit conversion
- Currency conversion
- Input validation using while loops
- User-friendly menu

## Technologies Used

- Python
- Functions
- Conditional Statements
- While Loops
- Exception Handling
- User Input

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
python calculator_converter.py
